# Эксперименты: какую модель и какие признаки выбрать

Результаты (`*_result.txt`) получены 14.11.2026 на версии проекта с **суточной** погодой —
именно они обосновали переход на линейную модель с почасовой погодой и направлением ветра.

| Скрипт | Что проверяет |
| --- | --- |
| `compare_models.py` | нелинейность (остатки по децилям признаков), 8 типов моделей, дополнительные признаки |
| `weather_ablation.py` | какие почасовые погодные переменные дают прирост |
| `wind_stability.py` | устойчиво ли влияние направления ветра в разных частях года |
| `fetch_sites.py` | скачивает почасовую погоду городов (Open-Meteo archive) в `data/weather_sites/` |
| `raw_recheck.py` | повторный разбор исходного файла: статусы прибора, «замёрзшие» каналы, связи каналов |
| `stops_and_baseline.py` | расписание остановов и показания прибора при нулевом расходе газа |
| `raw_dependencies.py` | часы сбоя прибора, производные показатели процесса, погода по региону |
| `low_flow.py` | часы с низким расходом; взаимодействие температуры и мощности |
| `fetch_isd.py`, `stations.py` | наблюдения метеостанций Южного Урала (NOAA ISD) против модельной погоды |
| `build_region_weather.py` | собирает погоду «в среднем по Челябинской области» из 7 городов — файл, на котором обучается модель |
| `south_ural.py` | города Южного Урала и наборы погодных признаков: что лучше объясняет пыль |
| `site_and_time.py` | сравнение погоды разных городов; сдвиг времени погоды ±6 ч |

Запуск (из папки `ecometeo/`):

```bash
python experiments/compare_models.py . data/weather_chel_2022_hourly.json out.txt
```

После перехода на почасовую погоду `artifacts/dataset.pkl` уже содержит почасовые `T_air`,
поэтому строки «суточная погода» при повторном запуске станут почасовыми: для точного
повтора нужен `dataset.pkl`, собранный с `--weather data/weather_chel_2022.json` на прежней версии кода.

Скрипты, написанные до перехода на среднюю погоду по области (`south_ural`, `stations`, `raw_dependencies`, `low_flow`), считали
строку «текущая модель» на погоде одного Челябинска; `python experiments/fetch_sites.py` нужен до `build_region_weather.py`.
